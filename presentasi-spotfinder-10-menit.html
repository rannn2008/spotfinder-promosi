SpotFinder
Project Presentation

Sistem Parkir Cerdas Berbasis IoT dan Web

Solusi untuk membantu pengguna mencari slot parkir, masuk dengan RFID, memantau status secara real-time, dan mengelola pembayaran secara digital.

By: Zahran Al Syafit Durasi: 10 menit
Pembuka 45 detik: perkenalkan nama proyek, nama pembuat, dan gambaran singkat bahwa SpotFinder menggabungkan aplikasi web, database, dan perangkat IoT untuk mengatur parkir.
01 - Cover0:45
Latar Belakang

Masalah parkir sering terlihat kecil, tetapi dampaknya besar.

Di area ramai, pengguna sering menghabiskan waktu untuk mencari slot kosong. Pengelola juga sulit mengetahui kapasitas, riwayat kendaraan, dan pemasukan secara cepat.

WaktuPengguna berputar mencari tempat kosong.
DataRiwayat parkir dan transaksi sering tidak terpusat.
AksesPalang masuk masih banyak yang manual.
LaporanPengelola butuh rekap yang cepat dan rapi.
Durasi 1 menit: jelaskan masalah nyata. Tekankan bahwa proyek ini dibuat karena parkir manual kurang efisien untuk pengguna dan kurang informatif untuk admin.
02 - Masalah1:00
Tujuan Proyek

Membuat parkir lebih cepat, tertata, dan mudah dipantau.

SpotFinder dibuat sebagai prototype smart parking yang menyatukan deteksi slot, autentikasi pengguna, dashboard, wallet, booking, dan laporan.

1

Real-time Slot

Status slot kosong, terisi, booking, atau pelanggaran dapat terlihat langsung.

2

RFID Access

Kendaraan masuk melalui verifikasi kartu RFID dan data member.

3

Cashless Wallet

Saldo, top-up, biaya parkir, dan booking fee dikelola dari aplikasi.

4

Dashboard Admin

Admin dapat melihat pengguna, transaksi, analytics, chat, dan gate control.

Durasi 1 menit: bagian ini menjawab kenapa dibuat dan apa targetnya. Gunakan kata sederhana: pengguna lebih cepat, admin lebih mudah mengelola.
03 - Tujuan1:00
Fitur Utama

Satu sistem untuk pengguna, admin, dan perangkat parkir.

A

Client Portal

Login, registrasi, profil, avatar, saldo, riwayat, dan chat support.

B

Booking Slot

Pengguna bisa memesan slot tersedia dengan biaya booking digital.

C

Admin Panel

Kelola RFID, member, top-up, tarif, analytics, history, dan laporan.

D

IoT Detection

ESP32 membaca sensor ultrasonik untuk mendeteksi kendaraan per slot.

E

Auto Gate

Servo membuka dan menutup palang setelah akses disetujui.

F

AI Voice

Asisten suara memberi notifikasi selamat datang, keluar, dan status sistem.

Durasi 1 menit: sebutkan fitur dengan cepat. Jangan terlalu teknis dulu, cukup jelaskan manfaat masing-masing fitur.
04 - Fitur1:00
Cara Kerja

Alur sistem dari pengguna datang sampai keluar parkir.

1

Login atau Daftar

Pengguna masuk ke portal client dan mendaftarkan data kendaraan.

2

Cek Slot

Dashboard menampilkan slot kosong dan rekomendasi slot terbaik.

3

Scan RFID

ESP32 mengirim UID ke server untuk verifikasi akses.

4

Sensor Membaca

Ultrasonik mendeteksi kendaraan dan memperbarui status slot.

5

Bayar & Keluar

Biaya dihitung otomatis, riwayat tersimpan, dan struk bisa dicetak.

Durasi 1 menit: jelaskan alur seperti simulasi. Ini bagian penting untuk membuat audiens paham cara penggunaan secara ringkas.

06 - UI1:00
Teknologi

Komponen web dan hardware saling terhubung melalui API.

Backend memakai PHP dan MySQL. Frontend memakai HTML, CSS, JavaScript, jQuery, dan Chart.js. Perangkat memakai ESP32, RFID RC522, sensor ultrasonik, OLED, LED, buzzer, dan servo palang.

PHP

Server App

Login, dashboard, transaksi, settings, report, dan API.

SQL

Database

Menyimpan users, sensor_status, parking_history, settings, dan topup_requests.

IoT

ESP32

Mengirim status sensor dan menerima perintah gate dari server.

RFID

Akses Masuk

Kartu member dipakai untuk validasi kendaraan sebelum palang terbuka.

API

Integrasi

Endpoint seperti check access, update sensor, auto exit, booking, dan chat.

AI

Voice Assistant

ElevenLabs TTS dan fallback browser voice untuk notifikasi suara.

Durasi 1 menit: sebutkan teknologi secukupnya. Jangan baca semua detail, cukup tunjukkan bahwa proyek ini full-stack dan terhubung ke hardware.
07 - Teknologi1:00
Cara Penggunaan Saat Demo

Urutan demo yang aman untuk presentasi 10 menit.

Untuk Client

  1. Buka halaman promosi SpotFinder, lalu klik Client Portal.
  2. Login atau registrasi pengguna dengan data kendaraan.
  3. Lihat saldo, status slot, rekomendasi slot, dan riwayat.
  4. Coba booking slot kosong, lalu cek perubahan status.
  5. Buka chat support jika ingin bantuan atau batal booking.

Untuk Admin

  1. Login admin dan buka dashboard utama.
  2. Perlihatkan slot real-time, activity feed, dan okupansi.
  3. Buka Users & Wallet untuk approve top-up atau tambah RFID.
  4. Tunjukkan analytics, settings tarif, dan riwayat transaksi.
  5. Gunakan gate control untuk membuka atau menutup palang.
Durasi 1 menit 15 detik: ini adalah script demo. Kalau waktu mepet, cukup jalankan 3 hal: cek slot, booking client, lalu dashboard admin.
